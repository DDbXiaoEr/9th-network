U 盘启动盘是重装系统、进 PE、跑 Linux live 的基础工具。制作一次，后面装机会省很多时间。

## 开始前

- 准备 8GB 以上 U 盘（制作过程会清空盘内数据）
- 下载系统 ISO 或 PE 工具箱
- 确认电脑是 UEFI 还是传统 BIOS

## Windows 做法

1. 下载 Rufus 或社团常用的 PE 工具箱。
2. 插入 U 盘，选择正确盘符，避免选成硬盘。
3. 引导类型选 ISO，分区方案：
   - 新电脑：GPT + UEFI
   - 老电脑：MBR + BIOS
4. 点击开始，等待写入完成，安全弹出。

## 进启动菜单

重启后按厂商快捷键进入启动菜单，常见键位：

| 品牌 | 启动菜单 |
| --- | --- |
| 联想 | F12 / Fn+F12 |
| 戴尔 | F12 |
| 华硕 | Esc / F8 |
| 惠普 | F9 |
| 小米 / 部分国产 | F12 |

选中对应 U 盘即可。若只有硬盘选项，到 BIOS 里打开 USB Boot，并关闭 Secure Boot 再试。

## 常见问题

- **U 盘进不去**：换 USB 口、换分区方案，或关掉 Secure Boot。
- **提示无启动介质**：镜像损坏，重新下载校验后再写。
- **写入很慢**：换 USB 3.0 口，或换质量更好的 U 盘。
