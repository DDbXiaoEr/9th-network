系统装完还不能直接用：没网卡驱动上不了网，缺显卡驱动会卡顿，未激活会有水印。按「联网 → 驱动 → 激活」处理即可。

## 先把网络打通

新系统经常缺网卡驱动。准备一份离线网卡包（驱动精灵万能网卡版、厂商官网 inf 等），装上后再更新其余驱动。

校园网认证、DNS 异常时，先确认网卡已启用、能拿到 IP，再处理认证客户端。

## 驱动安装顺序

1. 芯片组 / 网卡
2. 显卡（NVIDIA / AMD / Intel）
3. 声卡、触控板、蓝牙
4. 笔记本电源与热管理相关驱动

优先用设备厂商官网或 Windows Update，少用来路不明的「驱动大师全家桶」。装完重启，在设备管理器里确认没有黄色感叹号。

## 激活注意

- 正版密钥、学校批量授权或官网渠道更稳妥
- 不要随手跑来路不明的激活工具，容易夹带木马
- 激活失败先检查时间和时区，再核对版本（家庭版 / 专业版）是否匹配

装机完成后建议立刻改密码、开 Windows Update，并创建一个系统还原点。
